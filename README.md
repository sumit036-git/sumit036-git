## 🚀 Project Spotlight

### 🌌 Kerr Black Hole Simulator
Real-time 3D WebGL simulation of a Kerr black hole with relativistic gravitational lensing, Doppler-shifted accretion disk, and physics overlays inspired by Kip Thorne's work. This project demonstrates advanced 3D graphics and physics-based rendering.

**Tech:** TypeScript • Three.js • WebGL • Vercel  
**Repository:** [sumit036-git/Kerr-Black-Hole-Simulator](https://github.com/sumit036-git/Kerr-Black-Hole-Simulator)  
**Live Demo:** https://kerr-black-hole-simulator.vercel.app  
**Key Features:**
- Real-time 3D rendering with relativistic effects
- Doppler shift visualization on accretion disk
- Interactive camera controls
- Physics-based gravitational lensing

---

### 🌀 Gray-Scott Reaction-Diffusion
An interactive visualization of the Gray-Scott reaction-diffusion system, showcasing pattern formation and emergence through mathematical simulation. Perfect for exploring complex system behavior and beautiful mathematical patterns.

**Tech:** JavaScript • Canvas • React • Vercel  
**Repository:** [sumit036-git/Gray-Scott-Reaction-Diffusion](https://github.com/sumit036-git/Gray-Scott-Reaction-Diffusion)  
**Live Demo:** https://gray-scott-reaction-diffusion-sigma.vercel.app  
**Key Features:**
- Real-time pattern generation
- Interactive parameter controls
- Multiple reaction modes
- Beautiful emergent behaviors

---

### 🎵 Flute Musical App
Interactive browser-based flute simulator with keyboard-driven controls and visual feedback. A fun exploration of web audio and interactive UI design.

**Tech:** HTML • CSS • JavaScript  
**Live Demo:** https://flute-musical-app-html.vercel.app/  
**Key Features:**
- Keyboard-based note playing
- Real-time audio synthesis
- Visual feedback system
